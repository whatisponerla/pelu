# Sistema de Gestión de Turnos para Peluquería

## Descripción
Aplicación web para gestionar turnos de una peluquería. Los clientes podrán reservar mediante QR o enlace web sin crear una cuenta ni iniciar sesión.

El proyecto seguirá una estrategia Mobile First.

## Objetivos del MVP
- Permitir reservar turnos.
- Permitir administrar horarios.
- Permitir gestionar clientes.
- Evitar la doble reserva.
- Facilitar futuras integraciones.

## Tecnologías
- Frontend: React + Vite
- Backend: Express.js
- Base de datos: MySQL
- Desarrollo/pruebas: Linux Mint + XAMPP + Node.js + npm

## Roles
### Administrador
Crear, editar y eliminar horarios; ver reservas e historial.

### Cliente
Ver horarios disponibles y reservar turnos. No requiere autenticación.

## Filosofía
- Mobile First.
- Simplicidad antes que complejidad.
- No implementar funcionalidades innecesarias.
- Mantener una arquitectura mantenible.
- Favorecer reutilización de código.
